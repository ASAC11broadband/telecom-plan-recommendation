# 코사인 유사도 기반 요금제 추천

## 목적

가입 이력의 인기나 세그먼트에 의존하지 않고, **신규 사용자의 입력과 각 요금제의
속성 자체를 직접 비교**하는 콘텐츠 기반 추천을 설계했다. 신규 요금제도 속성만
입력되어 있으면 바로 추천할 수 있다는 점이 장점이다.

```
사용자 입력 → 최소 조건 필터 → 공통 벡터 변환 → 가중 코사인 유사도 → 보정·Top-5
```

## 벡터 설계

사용자 요구와 요금제 공급 정보를 아래 8개 공통 축으로 0~1 범위에 맞췄다.

| 사용자 입력 | 요금제 속성으로 대응 | 처리 방식 |
|---|---|---|
| 월 데이터 사용량 | 제공 데이터량 | 200GB 상한 정규화, 무제한은 최댓값 |
| 통화/SMS 필요량 | 제공 통화/SMS | 각각 1,000분·500건 상한 정규화 |
| 데이터/통화/SMS 무제한 필요 | 각 무제한 제공 여부 | 0 또는 1 |
| 예산 | 할인 적용 월 요금 | 낮은 예산일수록 가격 민감도를 높게 표현 |
| OTT 필요 | OTT 옵션 포함 여부 | 0 또는 1 |

할인가가 `0원`인 경우는 결측이 아니라 실제 프로모션 가격으로 보존했다. 성별·연령은
선호 유사도에 넣지 않았다. 연령 제한은 향후 요금제의 정형화된 가입 가능 조건이 확보되면
별도 하드 필터로 처리한다.

## 추천 로직

1. 데이터·통화·SMS의 최소 사용량과 무제한 요구를 충족하지 못하는 요금제를 먼저 제외한다.
2. 공통 벡터에 데이터 1.5배, 통화 1.0배 등 중요도를 적용해 **가중 코사인 유사도**를 계산한다.
3. 코사인 점수를 70% 반영한다.
4. 최소 조건을 넘긴 뒤에도 지나치게 큰 요금제를 고르는 문제를 줄이기 위해, 필요한 제공량에
   가까운 정도를 20% 보정한다.
5. 예산 적합도와 OTT 포함 여부를 각각 5% 보정해 최종 Top-5를 만든다.

코사인 유사도만 사용하면 데이터·통화 제공량이 큰 요금제가 과하게 상위에 오를 수 있다.
그래서 “최소 조건 충족”은 필터에서 보장하고, 순위에서는 **충분하지만 과하지 않은 제공량**을
선호하도록 분리했다.

## 100명 홀드아웃 결과

원본 합성 가입이력 40,000건 중 당시 요금제 스냅샷과 연결된 39,095건(97.74%)으로 평가했다.
100명을 분리하고, 원래 합성 과정에서 부여한 `source_plan_id`를 정답으로 사용했다.

| 지표 | 결과 |
|---|---:|
| 하드 필터 뒤 평균 후보 수 | 706.3개 |
| Top-1 정확도 | 0.1300 |
| Hit@5 | 0.3800 |
| MRR@5 | 0.2230 |
| 서로 다른 Top-5 조합 수 | 56개 |

이 점수는 실제 고객 만족도나 전환율이 아니라 합성데이터 생성 시의 가입 선택을 재현한
정도다. 그럼에도 세그먼트 인기 방식과 달리, 사용자 입력과 **요금제 스펙의 적합도**를
직접 설명할 수 있는 추천 경로를 남긴다는 데 의미가 있다.
